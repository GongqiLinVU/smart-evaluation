I. Complete programming code + User manual

(Subject to student's contribution and performance)


25pt HD

Code is complete, well-organized, and highly efficient. It is fully functional, well-documented, and adheres to best practices.
Manual is thorough, clear, and user-friendly, with detailed instructions and helpful screenshots or diagrams.

20pt D

Code is mostly complete and functional with good organization and documentation. Minor improvements needed.
Manual is clear and functional with good instructions and some helpful visuals.

15pt C

Code is generally complete with some organizational or documentation issues. Functionality may be limited.
Manual is adequate with basic instructions and some visuals, though clarity or completeness may be lacking.

10pt P

Code is incomplete or poorly organized, with significant issues in functionality or documentation.
Manual provides minimal instructions and visuals, with some areas unclear or incomplete.

5pt F

Code is significantly incomplete or non-functional, with major issues in organization and documentation.
Manual is poorly written, unclear, or missing, providing little to no help for users.


II. Technical Implementation Document

(Subject to student's contribution and performance)

30pt HD

Provides a clear, comprehensive, and insightful explanation of the logic behind each main function, demonstrating in-depth understanding.

The methodology is explained in a highly structured, clear, and concise manner, with strong justification for choices made.

Detailed and precise implementation steps are provided, showing a complete understanding of how each main function was implemented.

24pt D

Thorough explanation of logic with good clarity, showing solid understanding of each function’s purpose and structure.

Clear explanation of the methodology with appropriate reasoning for most decisions made.

Clear and mostly detailed description of implementation steps, demonstrating a solid understanding of the function implementation.

18pt C

Sufficient explanation of the logic for each function, with some minor gaps or lack of detail.

Methodology is described but lacks clarity or depth in some areas; reasoning is partially justified.

Adequate explanation of implementation, but with some minor gaps or lack of technical detail.

12pt P

Basic explanation of the logic, with limited depth, but overall understanding is evident.

Basic methodology is described, but there is little justification or reflection on choices made.

Basic implementation steps are mentioned but lack clarity or thoroughness.

6pt F

Fails to explain the logic or presents a disorganized, unclear understanding of how the main functions work.

No clear explanation of methodology, or the methodology provided is inadequate or poorly justified.

The implementation is poorly explained, with little to no detail on how the functions were implemented.
